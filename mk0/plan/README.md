# Plan · Investigación antes de GO comercial

1. Observar el flujo mensual en 8–12 contadores que utilicen herramientas distintas.
2. Seleccionar **una** tarea frecuente y medir tiempo, tasa de errores y frecuencia actual.
3. Comparar un flujo asistido con el flujo actual usando archivos anonimizados y resultados revisados por contador.
4. Documentar falsos positivos, falsos negativos, tiempos de corrección y valor económico.
5. Probar al menos un piloto con consentimiento y controles suficientes; validar precio mediante compromiso real, no solo encuesta.

**Umbrales experimentales, no resultados:** problema importante repetido en al menos 5/8 entrevistas, objetivo de ahorro ≥30% en tarea controlada y al menos 3 compromisos de piloto pagado. Ajustar gate si la evidencia contradice hipótesis.

**Salida:** GO / PIVOT / KILL. En ausencia de evidencia, **continuar investigación**, no declarar GO.
