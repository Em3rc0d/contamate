# Brainstorming · Problema

**Usuario objetivo hipotético:** contador peruano independiente o pequeño estudio que trabaja con múltiples empresas y utiliza Excel, XML y software contable variado.

**Trabajo por resolver:** preparar, revisar y documentar cierres mensuales sin perder trazabilidad entre documentos, registros, decisiones y períodos por empresa.

**Dolores a validar:** tiempo en conciliación y búsqueda de sustentos; seguimiento de documentos faltantes; mezcla involuntaria de expedientes; restricciones de datos confidenciales; equipos modestos.

**No asumimos:** que todo contador necesite voz, que reemplace un ERP, que la inferencia local sea suficientemente rápida en cualquier hardware, ni que haya disposición a pagar.
